# Лавка (qa-shop)

Небольшой интернет-магазин кофе, чая и аксессуаров: каталог, карточка товара, корзина,
промокоды, оформление заказа, регистрация и история заказов.

Стек: Node.js 20+, Express, одностраничный фронтенд на чистом JS. Данные хранятся в JSON-файле
(`data/db.json`), корзины и сессии — в памяти процесса.

## Запуск

Локально:

```bash
npm install
npm start            # http://localhost:3000
```

В Docker:

```bash
docker compose up -d --build   # http://localhost:3000
```

### Переменные окружения

| Переменная         | По умолчанию | Назначение                                                        |
|--------------------|--------------|-------------------------------------------------------------------|
| `PORT`             | `3000`       | Порт HTTP-сервера                                                 |
| `DATA_DIR`         | `./data`     | Каталог с файлом данных                                           |
| `ALLOW_TEST_RESET` | не задана    | `1` включает `POST /api/test/reset` — сброс данных к исходным     |

## Что умеет магазин

- **Каталог** — поиск по названию и описанию, фильтр по категории, сортировка по цене и названию.
- **Карточка товара** — описание, цена, остаток, выбор количества.
- **Корзина** — изменение количества, удаление, очистка. Нельзя положить больше, чем есть в наличии.
- **Промокоды** — `SALE10` (−10 %), `WELCOME500` (−500 ₽ при сумме товаров от 2000 ₽).
- **Доставка** — курьером 300 ₽, бесплатно при сумме заказа (после скидки) от 3000 ₽; самовывоз бесплатно.
- **Оформление заказа** — имя, телефон, способ доставки, адрес (для курьера), способ оплаты.
  После оформления остаток товара уменьшается.
- **Аккаунт** — регистрация, вход, выход, список своих заказов. Заказ можно оформить и без регистрации.

## API

Все ответы — JSON. Ошибки приходят в виде `{ "error": "...", "fields": { ... } }`.
Сессия определяется cookie `sid`.

| Метод  | Путь                        | Описание                                            |
|--------|-----------------------------|-----------------------------------------------------|
| GET    | `/api/health`               | Состояние сервиса                                   |
| GET    | `/api/categories`           | Категории                                           |
| GET    | `/api/products`             | Товары; параметры `search`, `category`, `sort`      |
| GET    | `/api/products/:id`         | Товар                                               |
| POST   | `/api/auth/register`        | Регистрация: `email`, `password`, `name`            |
| POST   | `/api/auth/login`           | Вход: `email`, `password`                           |
| POST   | `/api/auth/logout`          | Выход                                               |
| GET    | `/api/auth/me`              | Текущий пользователь                                |
| GET    | `/api/cart`                 | Корзина                                             |
| POST   | `/api/cart/items`           | Добавить товар: `productId`, `qty`                  |
| PATCH  | `/api/cart/items/:id`       | Изменить количество: `qty`                          |
| DELETE | `/api/cart/items/:id`       | Удалить товар                                       |
| DELETE | `/api/cart`                 | Очистить корзину                                    |
| POST   | `/api/cart/promo`           | Применить промокод: `code` (пустой — сбросить)      |
| GET    | `/api/delivery`             | Стоимость доставки; параметр `method`               |
| POST   | `/api/orders`               | Оформить заказ                                      |
| GET    | `/api/orders`               | Заказы текущего пользователя                        |
| GET    | `/api/orders/:id`           | Заказ                                               |
| POST   | `/api/test/reset`           | Сброс данных (только при `ALLOW_TEST_RESET=1`)      |

## Метрики

`GET /metrics` отдаёт метрики в формате Prometheus:

- `http_requests_total`, `http_request_duration_seconds` — запросы по методу, маршруту и статусу;
- `shop_orders_total`, `shop_revenue_rub_total` — заказы и выручка;
- `shop_cart_items_added_total`, `shop_users_registered_total`, `shop_login_failures_total`;
- `shop_active_sessions`, `shop_products_out_of_stock`;
- стандартные метрики процесса Node.js (`process_*`, `nodejs_*`).
